# LIC Insurance Data Analysis Using Python

## Project Overview
This project focuses on analysing a sample LIC-style insurance dataset using Python. The objective is to understand customer distribution, insurance policies, premium collection, policy status and claim amounts.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dataset Details
- 50 synthetic customer records
- 12 columns
- Customer information
- Insurance policy information
- Premium and claim details

## Project Tasks
1. Data loading and exploration
2. Data cleaning
3. Missing value analysis
4. Duplicate record analysis
5. Customer demographic analysis
6. Policy type analysis
7. Premium collection analysis
8. Claim analysis
9. Data visualization

## Key Visualizations
- Gender-wise customer distribution
- Policy type distribution
- Active vs Lapsed policies
- City-wise customer distribution
- Premium collection by policy type

## Skills Demonstrated
- Data cleaning using Pandas
- Data analysis using NumPy
- Exploratory Data Analysis (EDA)
- Data visualization using Matplotlib
- Business insights generation

## Conclusion
This project demonstrates how Python can be used to analyse insurance data, identify patterns and generate useful business insights.

## Disclaimer
This project uses synthetic practice data and is not affiliated with or based on actual LIC customer records.
